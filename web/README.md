# Elpha Room — WebSite

Next.js App Router website for Elpha Room.

## Getting Started

```bash
cd web
pnpm install
pnpm dev

Open http://localhost:3000
 in your browser.

Tech Stack

Next.js (App Router)

TypeScript

Tailwind CSS

Structure

app/: routes and root layout

components/: UI components and page sections

public/: static assets (images, favicon)
```
